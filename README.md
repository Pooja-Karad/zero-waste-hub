# Zero Waste Hub – Field Meets Digital Action

## Project Overview
Zero Waste Hub – Field Meets Digital Action is a Smart Waste Management System designed to connect citizens with waste collection teams. The system allows users to report waste, upload images, and automatically assigns waste collection teams.

## Features
- Report Waste Collection Requests
- Upload Waste Images
- Automatic Team Assignment
- Collector Portal
- Team & Vehicle Management
- Collection Records
- Request Status Tracking

## Technologies Used
- HTML
- CSS
- JavaScript
- LocalStorage

## Project Modules
- Home Page
- Reporter Portal
- Collector Portal
- Team History
- Collection Records
